# Integration Google Agenda (a venir)

Variables prises en charge:
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_REDIRECT_URI

Dans cette version, l'application fonctionne sans ces cles.
Si elles sont absentes, l'interface affiche "Integration Google Agenda non configuree".

Evolutions prevues:
- OAuth2 Google
- creation d'evenements apres approbation d'une visite
- synchronisation bidirectionnelle et gestion des conflits
